# 项目结构

```
shadowscan/
├── shadowscan.py            # 核心扫描器（确定性规则引擎）
├── ai_layer.py              # AI 增能层（--ai 显式开启）
├── README.md
├── CONTRIBUTING.md
├── LICENSE
├── assets.example.txt
├── env.example.sh
├── docs/
│   ├── 项目结构.md
│   ├── AI增能层说明.md
│   └── 运行指引.md
└── tools/
    ├── preflight_check.py
    ├── batch_scan.sh
    ├── verify_layer.py
    └── probe_policy.py
```

核心链路：资产清单 → 站点发现 → 框架指纹 → 上下文前缀收集 → 前缀 × 规则库扫描 → 聚合报告 →（可选）AI 增能层。
